# Darling Ingredients (darling-ingredients)
Darling Ingredients is a global developer and producer of sustainable natural ingredients from edible and inedible bio-nutrients, creating products for the food, pet food, feed, fuel, bioenergy, and fertilizer industries. Darling operates Diamond Green Diesel as a renewable diesel joint venture with Valero, and brands such as Rousselot (gelatin and collagen), Sonac, CTH, and EnviroFlight. Darling does not publish a public developer API.
